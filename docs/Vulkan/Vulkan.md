# What is Vulkan?
Vulkan is the cross-platform graphics and compute API created by the Khronos Group. 
Vulkan was developed in 2016 to solve many problems in the previous APIs, such as OpenGL and Direct3D. 
Vulkan provides a very thorough setup process with explicit memory allocation. This allows both the driver and the programmer to avoid guessing any of those settings.
Vulkan also allows the use of multi-threading by its architecture, which allows a programmer to create a high-performance graphics program.
Of course, Vulkan is not for everyone. If you are more interested in game development then you should use OpenGL, Direct3D and Metal or libraries like SFML, Raylib, SDL, etc. 
Personally I chose Vulkan because I'm interested in full control of my program, performance and a modern architecture API. 
So I'll use all of these advantages to create a modern graphics engine.
